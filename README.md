# Rabbit VS Turtle Race Game
## 게임 소개
- 각기 다른 이동 능력을 가진 동물들이 결승선을 향해 달리는 레이스 게임입니다.
- 동물들은 매 라운드마다 자신의 이동 방식에 따라 전진하며, 게임 진행 중 다양한 아이템 이벤트가 랜덤으로 발생합니다.
- 부스터를 통해 빠르게 전진할 수도 있고, 함정(Trap)에 걸려 뒤로 이동하거나, 얼음 상태(Freeze)에 걸려 다음 턴을 쉬게 될 수도 있습니다.
- 또한 방어막(Shield)을 통해 위험한 이벤트를 1회 방어할 수 있으며, 가장 먼저 결승선에 도착한 동물이 우승하게 됩니다.

## 1. 게임 시작
- 토끼
- 거북이

## 2. 라운드 진행
- 게임은 라운드 방식으로 진행됩니다.
- 각 라운드 마다 :
  1. 동물 이동
  2. 랜덤 아이템 이벤트 발생
  3. 현재 위치 출력
  4. 우승 여부 확인 - 결승선(20칸) 먼저 도착
순서로 진행됩니다.

## 3. 동물 이동
- 토끼(랜덤 1~5)
- 거북이(랜덤 1~3)

## 4. 랜덤 아이템 이벤트
### 아이템 종류 및 주요 기능
1. Booster
    - 앞으로 추가 3칸 이동
2. Trap
    - 뒤로 1칸 이동
      - 시작 위치(0칸)에서는 Trap 발동 불가
      - 방어막 보유 시 Trap 무효 처리
      - 현재 위치 출력
3. Freeze
    - 동물이 얼음 상태가 되며 다음 턴 쉬기
4. Shield
    - Trap과 Freeze와 같은 상태 이상 공격을 1회 방어

## 5. 주요 게임 메커니즘
### 랜덤 시스템
- 아이템 이벤트 발생 여부 랜덤
- 이벤트 대상 랜덤
- 아이템 종류 랜덩
이를 통해 매 게임마다 다른 결과가 나오도록 구현

# 객체 지향 설계
1. 추상 클래스 (모든 동물이 공통적으로 가짐)
- 이름(name)
- 위치(position)
- 얼음 상태(frozen)
- 방어막 상태(hasShield)를 관리
+ 또한 동물마다 이동 방식이 다르기 때문에 move() 메서드를 오버라이딩하여 구현

2. 인터페이스(Item 인터페이스)
- 모든 아이템은 `run(Animal animal)` 메서드를 공통적으로 사용

3. 다형성(타입 하나로 여러 아이템 객체를 처리할 수 있도록 구현)
- `Item item = itemFactory.createRandomItem();` 
-  `item.run(target);`

4. Factory 패턴
   - 아이템 생성 책임을 분리하기 위해 ItemFactory 클래스를 사용 
   -> 이를 통해 객체 생성과 게임 진행 로직의 결합도를 낮추고 유지보수성을 높임

## 구현 중 고민한 부분
### position 음수 처리 문제
- Trap 사용 시 동물의 위치(position)가 음수가 되는 문제가 발생
- 이를 해결하기 위해 moveStep() 내부에서 position 값이 0보다 작아질 경우 자동으로 0으로 보정하도록 구현
- `if(position < 0) {position = 0;}`
